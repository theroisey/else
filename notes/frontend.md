# Frontend system and private interaction rules

React/TypeScript, Vite, Tailwind semantic CSS variables, Font Awesome free-solid, TanStack Query, React Hook Form, and configured JIT-free Zod provide one interface. Source ownership: `app` routes/query defaults, `features/auth` identity/current grants, `features/shell` shell/navigation, explicit domain feature directories, `services/authenticated.ts` same-origin transport, and `components/ui` behavior/style primitives.

## Visual identity

Warm ivory/stone light surfaces and independently layered graphite dark surfaces use centralized text/border/status/chart tokens. Manrope operational typography pairs sparingly with Instrument Serif headings; self-hosted OFL notices ship. Ruled financial/operational sections, compact navigation, 1px separators and modest radii carry the identity. Avoid floating metric grids, gradients, fake dashboards and decorative luxury effects.

The authentic owner-supplied Roisey SVG path is preserved with 46:64 viewBox/aspect ratio and currentColor. Shell/login sizes are deliberate; browser tabs use the owner's supplied 16px and 32px PNG favicons without resampling. Website inspection was unavailable, so taupe is the interface accent choice rather than a claimed website brand color. Do not fabricate a brand quotation.

Mobile home-screen artwork derives from the original 2048×2048 `frontend/artwork/else-app-icon.png` (SHA-256 `33d87362bddebaae0c0038518fd1e79d11a118be11b5dcb8fcae26b1bc641f5d`). Regenerate committed derivatives with `python3 frontend/scripts/prepare-mobile-icons.py` (requires Pillow). Each size is resampled directly from the master with Lanczos and mild edge sharpening, then saved as a lossless PNG without cropping or changing proportions. iOS uses `/apple-touch-icon.png` at 180px plus `assets/apple-touch-icon-152.png` and `assets/apple-touch-icon-167.png`; Android uses `assets/android-chrome-192.png` and `assets/android-chrome-512.png`. The shell mark is `assets/roisey-logo.svg`, with its original SVG geometry unchanged. Legacy versioned icon files and redundant master/wrapper files are removed from public assets. Updated manifest and touch-icon references refresh cached metadata; canonical and precomposed root paths retain Safari discovery. Keep `purpose: any` to avoid adaptive-mask cropping. The stable `/app` manifest ID/start URL and root scope include sign-in. A bounded service worker caches build-verified immutable JS/CSS/fonts only; private work remains online. Pingora allowlists known icon files with correct MIME types and revalidated ETags. Physical installation remains a device check.

Light/Dark/System preferences persist and System follows prefers-color-scheme. An ordinary blocking same-origin bootstrap sets the theme before paint under strict CSP; React and cross-tab storage share validation. Restricted storage fails gracefully. Never reintroduce inline/eval or data-font allowances. Vite assetsInlineLimit stays zero; Font Awesome CSS is bundled with runtime CSS injection disabled. All schema consumers use `lib/validation` configured Zod rather than triggering its code-generation probe.

TextField/SelectField/Button share label/body/help/error geometry and CSS subgrids for the tallest localized label. Desktop controls are 40px, compact actions 32px, coarse/mobile targets 44px with 16px inputs. Preserve loading labels, visible focus, native selection, zoom, reduced motion, semantic named tables and local keyboard scrolling. Drawers/dialogs trap focus, close on Escape and restore it; destructive confirmation starts at Cancel.

## Service worker policy

Production keeps the existing secure-context registration after load with updateViaCache none. The worker preserves the original network Request and its credentials, including same-origin clearance cookies. Separate header-free/referrer-free keys belong only to Cache Storage. Only exact build-generated immutable JS/CSS/font URLs with matching MIME, URL, length and SHA-256 are eligible. Documents, APIs, media, mutable entries, query variants, Authorization/range requests and explicit no-cache/reload/no-store reads bypass the cache. Error, redirected, HTML challenge and mismatched responses cannot be stored. No credentials, sessions, grants, drafts or financial commands enter Cache Storage.

The deterministic build version owns at most 128 entries / 4 MiB with 1 MiB per entry and four pending writes. Cache failures preserve normal networking. There is no precache waterfall. Activation deletes obsolete caches only under the existing application-owned prefix, including the earlier v1 cache. Normal waiting activation preserves open work: no skipWaiting, clients.claim, controller-change reload or automatic retry. Save work and close existing panel tabs to activate an update. The application remains online-only for documents and private operations. Worker/HTML/bootstrap files revalidate; hashed files remain immutable. See [static delivery](static-delivery.md).

## Data and drafts

Domain parsers strictly bound exact DTO fields, client/parent identity, period/currency/generation context, exact numeric strings, dates, unique ordered pages/cursors and safe labels. Never infer a grant from role names or a write capability. Optional client context is independently authorized, so task/planning/reminder/finance-only deep links do not probe unrelated records. Commands/search use actual registered pages and the existing authorized client-name endpoint; global task and technical queues use their real scoped endpoints; commercial finance filters use persisted records.

Query keys partition actor/grants/client/parent/selection. Current guards run before display and late responses check mounted/current context. Loading or failed read-only history hides previous private data; grant changes remove unauthorized candidate titles. Same-actor authorized form placeholders can preserve a draft across a grant refresh without retaining unrelated resource titles. Do not key the entire app by grants: that destroys planning/reminder historical-reference drafts. Financial recovery controllers reset separately on identity/grant/auth changes.

Forms retain memory-only original revision and metadata/reference selections outside candidate pages. Background refresh does not replace a mounted draft. Stale writes block until explicit reload/discard; unknown writes do not retry automatically. Preserve exact payment/copy command UUID, original normalized payload and revision above routes for identical reconciliation after Back. Reload/unload/auth loss discards private in-memory recovery; manual history review must precede replacement. A conflict or absent checked history row does not prove noncommit.

Credential inputs are uncontrolled, clear before request and on unmount, and never enter React/query state, browser storage, URLs, screenshots or logs. Clearing does not guarantee physical JavaScript memory erasure. Payment references are masked until explicit reveal and absent from hidden labels; reveal resets with page/access changes. Costs require current manager access and never appear in copied billing terms.

## Time, numbers and language

Financial values stay exact strings/BigInt through input/display. Number is limited to bounded chart coordinates; exact labels/tables retain original values. Provider missing dates stay missing. Keep strong numeric alignment, tabular digits, large currency wrapping and contained chart panning in both themes.

Task/planning dates use stated device IANA zone; unchanged values preserve exact original microseconds and later fold occurrences. Changed spring gaps fail; changed overlaps use the documented first occurrence. Reminders retain explicit wall/zone/offset and require Earlier/Later choices for new ambiguous schedules. Use plain time text rather than native datetime-local that discards precision. Calendar dates remain calendar dates; application instants use reviewed locale/timezone display.

English is canonical, with complete Turkish, Romanian, German and French namespaces. Translate UI/static errors/definitions, never arbitrary customer text, machine IDs, currencies or IANA zone names. Locale formatting preserves exact money and interpolation. Persist nonsecret appearance/language; own-account language changes use current auth/CSRF and late-response ordering. Keep long translated labels/domain/client/email stress behavior and no document overflow.

## Verification

`make check` runs typed/linted source and meaningful unit/domain tests. `make test-browser` creates its own random loopback origin/private SQLite fixture and serves built assets through actual Pingora. Image mode uses the exact image with only a private synthetic data mount and nonroot invoking UID; the independent runtime gate verifies default production UID 65532. The fixture helper is host-only and refuses unmarked/nonprivate directories. Never direct it at existing data or replace production responses with fake providers.

Actual-image browser workflows cover login/cookie/expiry/revocation/admin/client/tasks/plans/reminders/activity/audit/finance/pricing/overview/providers/websites/language and light/dark responsive controls. Await the destination heading before editing fields shared with the outgoing route, such as provider setup/report dates; locator visibility alone can target the outgoing form during concurrent navigation. CSP attack probes test actual page headers; ordinary eval probe is a single test-only same-origin script fulfilled by Playwright, not a production artifact/endpoint. Traces/video/credential screenshots are disabled. Keep clearly synthetic screenshots temporary CI evidence rather than a stale committed image gallery.

## Daily operations

Below 1024px, the shell replaces the desktop sidebar with a fixed bottom navigation: Today, Tasks, Requests, Clients and More, filtered by the same current grants. More opens the shared keyboard-trapped dialog as a bounded bottom sheet; Escape restores its trigger, navigation focuses content, and resizing to desktop closes it. Every remaining authorized destination stays available there. The header has no hamburger. Safe-area insets and workspace bottom clearance keep the bar away from the home indicator and form actions. Viewport fitting covers installed iOS/Android displays.

Shared inputs cap their inline size, fieldsets can shrink below their native min-content size, and native date/time controls discard iOS intrinsic appearance while retaining their browser picker and calendar values. Do not mask date overflow by clipping the form. Responsive pricing checks measure date controls against their field and sibling textarea, preserve entered dates, and hit-test the submit button above the bottom bar in both themes.

Mobile regressions extend existing browser scenarios rather than adding another suite. A media-query external store mounts mobile controls only below the desktop breakpoint; resizing unmounts any open sheet and restores scroll, without remounting page content or financial recovery. Chromium exercises 360/390/430/820px pricing forms in English/Turkish and both themes, all five locales on the client filters, keyboard navigation, permission-filtered links, breakpoint changes and emulated portrait/landscape safe areas. Physical iOS/Android testing is separate; the local WebKit download was blocked by network policy. No dependency, authentication, financial, or database contract changes are required.

`features/operations` owns Today, global task/request queues, request evidence/timeline/delivery/review, teams/brand assignments, notifications, commercial services/periods/corrections, recurring templates and preferences. Default navigation starts at Today; secondary portfolio/administration stays under More. Client tabs group Summary, Work, Websites, Finance and More without removing original modules. Human names replace raw IDs in operational selectors and payment history.

Authenticated current-grant refresh runs every 30 seconds in an active tab and on focus/reconnect; notification polling uses the same lightweight interval. Every API still enforces fresh authorization. Filters and long histories progressively disclose bounded paged queries. Before/after images lazy-load through protected same-origin requests. All five locales share strict operation DTO validation and accessible theme-aware controls.

Client More uses an explicit disclosure button and in-flow advanced links, rather than an absolute popup inside an overflow-scrolling tab bar. Both rows wrap without clipping on mobile. Advanced destinations retain their active context; primary navigation closes the disclosure. Escape closes it and restores trigger focus. Current grants filter the links on every render. Browser verification must hit-test a revealed link before scrolling or clicking: DOM visibility alone cannot detect the original clipped-popup failure.

Mutations disable duplicate submission and retain their original command, normalized payload and revision on uncertain outcomes. Reconciliation retries that command only; an explicit discard warns users to inspect history first. Brand/task/finance query invalidation connects existing collection screens and the new service-period views. Appearance/system bootstrap, original SVG, self-hosted typography and keyboard/mobile geometry remain shared.

## Refinement and session renewal

Filter surfaces share inset horizontal padding and localized label subgrids; historical reminder owner IDs are revealed only when selected. Section guides remain keyboard accessible. Route changes commit immediately and focus the new main region, without navigator interception, delayed actions, inert exits, DOM snapshots or page opacity animations. Fade animations belong only to loading skeletons and button progress; menus, dialogs, drawers and pages appear immediately. Reduced motion remains respected. My Access is removed from navigation, account links and search; its old URL redirects to Today. Appearance/language remain in Settings and the account menu. Current-grant refresh continues on reconnect/focus and active polling. Service Status UI is removed; `/health` and `/ready` remain.

The login header contains only authentic branding. Appearance and language live in the footer as text buttons opening the shared focus-trapped choice dialog; account/settings selectors retain their existing behavior. Mobile account controls use a compact accessible icon, with the full identity inside the menu.

Client forms and profiles omit the retired legacy website field; independent properties remain in Websites without primary designation controls or badges. Profile writes omit the legacy key so even malformed historical values remain untouched.

Production shares hashed runtime/core chunks and defers route code and four optional language packs. Each selected language loads in one request; English remains the local fallback. A build gate limits initial JavaScript to 250 KB gzip, each optional language to 70 KB and total JavaScript to 3 MiB. Native gzip/immutable asset caching and the separate ordinary blocking theme bootstrap remain. Tests, fixtures and secrets never enter production assets. Critical Latin fonts preload; Latin/extended-Latin Manrope subsets cover the operational languages while retaining OFL notices.

`app/route-loaders.ts` owns the import functions; `lazy-page.ts` shares resolved public modules between intent preloading and rendered pages. Ready code renders synchronously without a lazy fallback. The chosen page wrapper stays stable per mount, preserving drafts after background renders. The authenticated workspace and financial recovery controllers load separately from sign-in and stay mounted across workspace navigation. Current-destination code can load alongside the session check, but authorization still gates every rendered page and protected read. Failed code loads leave an accessible reload action; no automatic reload can discard a draft.

Login and a restored workspace warm a bounded set of common public modules; link hover/focus warms the requested destination. Save Data/2G skip speculative work. Importing modules never prefetches private data. Existing actor/grant/selection query keys, bounded pagination, abort signals, polling and invalidation rules remain; independent reconciliations now run concurrently after confirmed writes. Scope search and workspace search coalesce typing for 200 ms without displaying results for an obsolete search. Notifications navigate within the live application rather than forcing a document reload.

Formatter caches contain at most 64 configurations per formatter type, keyed by locale/options, without retaining amounts or business text. Dates without an explicit timezone are recreated to follow device timezone changes. Appearance shares one browser/media listener set; its synchronization subscription stays outside route rendering. Initial HTML shows a genuine loading indicator before React starts. Short transform-only entry/press feedback uses shared motion tokens and immediate focus/navigation; opacity fades remain confined to loading indicators. See [measurements and audit](frontend-performance.md).

Auth refresh uses same-origin, HttpOnly rotating cookies and CSRF. Current-session discovery renews near expiry or after access expiry, under a same-origin Web Lock and a per-tab queue. The fixed seven-day family deadline never slides. Logout is serialized with renewal and revokes the family even after access expires. A revoked identity cannot refresh; no business mutation is blindly retried. Browsers without Web Locks retain per-tab serialization; truly concurrent refresh from those sibling tabs can require reauthentication under strict replay protection.

Browser alerts are opt-in per account/browser in Settings, require HTTPS or loopback secure context and ask for permission only from a deliberate click. Polling continues in a background tab only when enabled. Each new batch produces one generic native notice, without brand/request names, amounts, comments or image evidence. An initial inbox load never creates historical alert spam; Web Locks plus a timestamp watermark suppress sibling-tab duplicates. Without Web Locks only the focused tab delivers native alerts. Permission denial/unsupported APIs preserve the in-app inbox. Clicking an alert opens the authorized notification page, and leaving the account/grant context closes it. This is open-panel delivery, not service-worker push after closing the browser.

Local `make check-changed` checks affected sources and related frontend tests; shared auth/components/catalog/build changes fall back to the full frontend suite. Backend changes retain full Rust checks. CI and `make check` remain complete release gates. VM workers retain per-file isolation while reusing processes to avoid repeated startup. Pure exact-value matrices share setup while preserving every boundary and report the offending input. Safe standalone calculation/date tests use Node rather than constructing a DOM.

Sign-in reads native, uncontrolled fields on submit, without React updates for individual keystrokes; the password clears synchronously before transport. A newly loaded workspace focuses its main region after mount so Save Data/cold chunks cannot strand keyboard focus. Exact-image checks verify all deferred script bytes, compression fallback, immutable caching and initial/language budgets.

See [static delivery](static-delivery.md) for the public worker, credential preservation, cache bounds, safe waiting updates, startup recovery, asset validation and optional Cloudflare beacon CSP. The public worker adds no push or offline business operations.

OAuth consent survives sign-in through narrowly allowed UUID destinations; capabilities have localized labels and optional brand scope.
