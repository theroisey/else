# HTTP Foundation

## Decisions

Issue #2 uses only the Go standard library and requires Go 1.27.1. Configuration is explicit and rejects empty, malformed, unbounded, or inconsistent values without echoing raw values. Default binding is loopback.

Only liveness and readiness routes exist. Readiness deliberately returns 503 until Issue #4 wires a real PostgreSQL checker; process liveness cannot stand in for database health. Dependency checks carry a deadline and request ID. No business access or audit write is implied by public health endpoints.

Request IDs are generated by the backend rather than trusted from a caller. Logs use recognized route/method labels and exclude raw paths, queries, headers, bodies, transport diagnostics, and panic values. This preserves useful correlation while avoiding secret-bearing log fields. Raw transport diagnostics are replaced by a safe structured event.

Graceful shutdown uses a fresh bounded shutdown context rather than prematurely cancelling active request contexts. Readiness turns unavailable before draining. Timeout closes active connections and preserves the shutdown error internally.

## Environment constraint

No global Go installation was present and Docker daemon was not running. An official Go archive was downloaded into temporary storage, verified by its published SHA-256, and used with temporary caches. Real-listener tests require localhost socket permission. No global toolchain, production credentials, or Docker environment was modified.
